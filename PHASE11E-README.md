# Phase 11E — Qaida Learning Intelligence

Requires Phase 11D.

Adds:
- mistake history
- student skill scoring
- weak-area detection
- targeted teacher homework
- student route `/portal/student/qaida-progress`
- teacher route `/portal/teacher/qaida-intelligence`
- student intelligence/homework APIs
- teacher homework API

Install:
1. Copy files to project root.
2. Append `phase11e-qaida.css` to `app/globals.css`.
3. Run `supabase/phase11e_qaida_intelligence.sql`.
4. Run `npm run build`.
5. Deploy with `npx vercel deploy --prod`.
